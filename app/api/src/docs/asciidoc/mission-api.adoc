=== 응답

==== Mission Status

|===
| status | 타입 | 설명

| `READY`
| String
| 도전하기 전 상태

| `IN_PROGRESS`
| String
| 도전 중인 상태

| `SUCCESS`
| String
| 인증에 성공한 상태

| `FAILURE`
| String
| 인증에 실패한 상태
|===

==== Mission Activity

|===
| status | 타입 | 미션 종류 | 설명

| `USE_PUBLIC_TRANSPORT` | String | 기본 미션 | 대중교통 이용하기 (따릉이 포함)
| `RECYCLE` | String | 기본 미션 | 분리수거 하기
| `USE_STAIRS` | String | 기본 미션 | 엘리베이터 대신 계단 이용하기
| `USE_DIGITAL_RECEIPTS` | String | 기본 미션 | 종이 영수증 대신 스마트 영수증 받기
| `USE_TUMBLER` | String | 기본 미션 | 텀블러 사용하기
| `UNPLUG_ELECTRONICS` | String | 기본 미션 | 사용하지 않는 전기 코드 뽑기

| `USE_REUSABLE_CONTAINERS` | String | 오늘의 미션 | 다회용기에 음식 포장하기
| `VISIT_VEGAN_CAFE` | String | 오늘의 미션 | 비건 카페 가기
| `USE_SHOPPING_BAGS` | String | 오늘의 미션 | 장바구니 이용하기
| `BUY_LOCAL_PRODUCE` | String | 오늘의 미션 | 지역 농산품 구매하기
| `USE_ECO_FRIENDLY_PRODUCTS` | String | 오늘의 미션 | 친환경 제품 사용하기
| `VISIT_REFILL_STORES` | String | 오늘의 미션 | 리필샵 방문하기
| `PLOGGING` | String | 오늘의 미션 | 플로깅

| `PLANT_TREES` | String | 스페셜 미션 | 나무 심기
| `BEACH_COMBING` | String | 스페셜 미션 | 비치코밍
|===
